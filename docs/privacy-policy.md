# 解锁提醒 · 隐私政策

最后更新：2026-09-08

「解锁提醒」是一款纯本地工具，**不联网**（应用未申请 INTERNET 权限，技术上无法上传任何数据）。

## 我们处理哪些数据

| 数据 | 用途 | 存储位置 |
|---|---|---|
| 解锁事件、倒计时设置 | 核心功能：解锁后开始倒计时 | 仅本机 SharedPreferences |
| 应用前台使用时长（UsageStats） | 到点提醒页展示"本轮各应用用了多久" | 仅本机内存即时计算，不落盘、不上传 |
| 通知/悬浮窗等权限状态 | 界面显示 ✓/✗ | 仅本机 |

## 我们不做的事

- 不采集、不上传、不分享任何个人数据（无网络权限，物理上不可能）
- 不含广告、不含任何第三方统计/追踪 SDK
- 不读取应用内容，只统计"哪个应用在前台、多长时间"

## 权限用途说明

- 显示在其他应用上层（悬浮窗）：到点时在您正在使用的应用上方弹出全屏提醒
- 使用情况访问：统计本轮各应用前台时长
- 全屏意图 / 通知：到点发出可交互的提醒通知
- 精确闹钟：倒计时到点准时触发（含省电模式）
- 开机自启（接收开机广播）：重启后恢复您开启的监控

您可以随时在系统设置中关闭上述任意权限；关闭后对应功能降级（如无悬浮窗时到点改为通知提醒），其余功能不受影响。
